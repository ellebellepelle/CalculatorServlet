# 💰 CalculatorServlet

A simple web-based compound interest calculator built using Java Servlets and JSP.

## 🌍 Live Demo
https://calculatorservlet.onrender.com

---

## 📌 Description
This application calculates compound interest based on user input such as principal amount, interest rate, number of years, and compounding frequency.

---

## ✨ Features
- Calculate compound interest
- Simple and clean UI
- Input validation
- Uses Java Servlets and JSP

---

## 🛠️ Tech Stack
- Java (Servlets)
- JSP
- Apache Tomcat
- Maven
- Docker
- Render (deployment)

---

## 🚀 How to run locally

1. Install Java (JDK 17+)
2. Install Apache Tomcat
3. Open project in IntelliJ IDEA
4. Add Tomcat Server (Local)
5. Deploy artifact: CalculatorServlet:war exploded
6. Run server
7. Open in browser:
   http://localhost:8080/CalculatorServlet_war/

---

## ⚠️ Notes
- Free Render instances may take ~30 seconds to start after inactivity
